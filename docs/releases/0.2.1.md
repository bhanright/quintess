Quintess 0.2.1 fixes one bug in 0.2.0.

## Fixed

- Opening the Bookmarks panel (or replying to a comment in the Comments panel) made the sidebar grow wider and wider without end. The sidebar now keeps its width.

## Downloads

- **Windows 10/11 (x86_64):** `Quintess-0.2.1-setup.exe`. Installs for your user account, with no administrator rights. The installer isn't code-signed yet, so Windows may show a SmartScreen warning.
- **Linux (x86_64):** `quintess_0.2.1_amd64.deb` for Ubuntu and Debian, or `quintess-0.2.1-linux-x86_64.tar.gz` with an install script for other distributions. See [Installing on Linux](https://quintess.cc/guide/#installing-on-linux).

Each file has a `.sha256` checksum beside it. Everything new in 0.2.0 is described in the [0.2.0 release notes](https://github.com/bhanright/quintess/releases/tag/v0.2.0).
