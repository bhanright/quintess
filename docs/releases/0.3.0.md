Quintess 0.3.0 is one program instead of two, and a smaller download.

## Changed

- **One program.** The app and the command-line tool are now the same `quintess` program. Run it with a command (`quintess merge …`, `quintess --help`) and it works in the terminal; run it with nothing, or with files, and the app opens. To open a file whose name is also a command, use `quintess -- merge` or `quintess ./merge`.
- **Smaller.** The Windows installer is 37.6 MB, down from 50.1 MB, and the installed programs take 81 MB instead of 138 MB.
- **Terminal use on Windows.** A tiny `quintess.com` launcher sits beside `quintess.exe`, so typing `quintess` in Command Prompt or PowerShell prints in order, waits for the command to finish, and works with pipes, redirection and Ctrl+C. Opening a PDF from Explorer shows no console window. The installer now adds Quintess to your PATH by default (per user, removed on uninstall).
- **Linux.** The packages install one `quintess` program, and the menu entry and PDF association use it.

## Upgrading

- The installer removes the old `quintess-app.exe` and moves the PDF association, Start menu and desktop shortcuts to `quintess.exe`. A taskbar pin of the old program stops working; pin Quintess again.
- If you turned off the PATH option when installing 0.2, upgrading keeps it off. Reinstall with the option checked to type `quintess` in a terminal.
- On Linux, upgrading the .deb or rerunning `install.sh` replaces the old `quintess-app` link.

## Downloads

- **Windows 10/11 (x86_64):** `Quintess-0.3.0-setup.exe`. Installs for your user account, with no administrator rights. The installer isn't code-signed yet, so Windows may show a SmartScreen warning.
- **Linux (x86_64):** `quintess_0.3.0_amd64.deb` for Ubuntu and Debian, or `quintess-0.3.0-linux-x86_64.tar.gz` with an install script for other distributions. See [Installing on Linux](https://quintess.cc/guide/#installing-on-linux).

Each file has a `.sha256` checksum beside it. What's new in 0.2 is in the [0.2.0 release notes](https://github.com/bhanright/quintess/releases/tag/v0.2.0).
