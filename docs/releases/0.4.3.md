Quintess 0.4.3 makes exported Word documents display correctly in word processors other than Word.

## Fixes

- **Word export:** the text of an exported Word document is now placed in text boxes fixed to the page, which Word, LibreOffice and WordCraft all show where they belong. Before, word processors other than Word ran all the text down the page.

This release is for Windows only for now; the Mac and Linux builds will follow.
