§01

Edit existing text. Redact sensitive details.

p. 02

edit text

Change the words that are already there.

Click a line or paragraph and type. Paragraphs re-wrap, bold and italic carry through, and Quintess uses the document's font where it can. A preview shows which lines will move before you apply.

Spelling mistakes are underlined as you type in page text, comments and form fields. Right-click for suggestions, or press F7 to review them. Nine dictionaries are included, with more available in the app.

redaction

Black boxes that remove, not cover.

Text, pictures and shapes under a box are taken out of the file. Quintess then looks for the removed text elsewhere in the file and reports what it found and anything it couldn't check.

    signatures

    Sign a PDF. Check who signed it.

    Sign with a certificate file, a certificate installed in Windows, or an identity you create in Quintess. Add a trusted timestamp, and check signatures for changes and certificate trust, with the result explained in plain language.

    rev 1signed revision ✓
    rev 2comment added
    rev 3field filled

    Later edits keep the signed revision available to check. Readers show that changes were made after signing. Redaction rewrites the file and invalidates existing signatures; Quintess warns first.

    Your PDF files aren’t uploaded. Editing, OCR and redaction run on your computer. Optional trusted timestamps send a fingerprint of the signature to a timestamp server.

    Network access is used for update checks you enable, dictionaries you download, web pages you convert, links you open, and timestamp or certificate-status requests you choose. No telemetry.

    §05

    Questions.

    p. 06
    Is it really free?

    Yes. Quintess is open source under MIT or Apache-2.0. There is no paid tier, no trial and no ads.

    Can Quintess replace Acrobat?

    For many people, yes: it edits text and pictures, redacts, fills and creates forms, signs, runs OCR and converts documents. It doesn't promise every Acrobat feature or identical results. Try it on copies of your documents and check the results before you switch.

    Windows says "Windows protected your PC". Is that normal?

    Yes, for now. The installer isn't code-signed yet, so SmartScreen warns about it. Download it only from the Quintess release page on GitHub, then compare its SHA-256 with the checksum published beside it (in PowerShell: Get-FileHash .\Quintess-*-setup.exe). A match shows the file is exactly the one released. If you decide to go ahead, choose More info, then Run anyway.

    Does Quintess work on Linux or Mac?

    Linux is supported in version 0.2.0, with x86_64 downloads: a .deb package for Ubuntu/Debian and a .tar.gz archive with an install script. See the Linux installation instructions for requirements and setup. There is no Mac release.

    Can I edit the text in every PDF?

    Quintess edits the text a PDF contains, a line or a paragraph at a time, and re-wraps paragraphs. It keeps the document's fonts when they have the letters you type and substitutes a close match when they don't. Scanned pages are pictures: OCR makes them searchable and lets you select and copy the text, but the page itself stays an image. Text drawn as outlines can't be edited as text.

    How do updates work?

    On first launch, Quintess asks whether to check GitHub for new versions. If you say yes, it checks at most once a day and asks before downloading anything. You can also check by hand from the Help menu.

    Does it need administrator rights?

    The Windows installer runs without administrator rights and installs for your user account. Installing the Linux .deb package requires administrator rights. See the Linux installation instructions for the tarball's setup options.
