§02

What Acrobat doesn't do.

p. 03

Linux.

A .deb for Ubuntu and Debian and a tarball for other distributions. Acrobat has no Linux version.

No account. No subscription.

Download it and use it. There's nothing to sign in to or renew, and your documents stay on your computer.

Text that wraps around pictures.

Square, tight or top-and-bottom wrapping, as in Word. Move the picture and the paragraph follows.

Redactions you can check.

After redacting, Quintess searches the page text, metadata, comments, form data and attachments it can read for any word that should be gone.

One form, every row of a spreadsheet.

Fill a PDF form from a CSV or Excel file and get one filled copy per row, named the way you choose.

Folders that process themselves.

Record a set of steps, then watch a folder: every PDF dropped in gets them. Or script it all from the command line.

Everything else you'd expect from a PDF editor is there too: editing text, comments, forms, signatures, OCR, conversion and more. See the user guide.

§03

Questions.

p. 04
Is Quintess really free?

Yes. It's open source under the MIT or Apache-2.0 license. There's no paid version, no account and no subscription.

Can Quintess replace Acrobat?

For many people, yes: it edits text and pictures, redacts, fills and creates forms, signs, runs OCR and converts documents. It doesn't promise every Acrobat feature or identical results. Try it on copies of your documents and check the results before you switch.

Windows says "Windows protected your PC". Is that normal?

Yes, for now. The installer isn't code-signed yet, so SmartScreen warns about it. Download it only from the Quintess release page on GitHub, then compare its SHA-256 with the checksum published beside it (in PowerShell: Get-FileHash .\Quintess-*-setup.exe). A match shows the file is exactly the one released. If you decide to go ahead, choose More info, then Run anyway.

Does Quintess work on Linux or Mac?

Linux is supported in version 0.2.0, with x86_64 downloads: a .deb package for Ubuntu/Debian and a .tar.gz archive with an install script. See the Linux installation instructions for requirements and setup. There is no Mac release.

Does Quintess send my documents anywhere?

No. Your PDF files aren’t uploaded. Editing, OCR and redaction run on your computer. Network access is used for update checks you enable, dictionaries you download, web pages you convert, links you open, and timestamp or certificate-status requests you choose. Optional trusted timestamps send a fingerprint of the signature to a timestamp server. No telemetry.
