A few useful extras.

A native Linux app.

Choose a .deb for Ubuntu or Debian, an AppImage, a Flatpak or a tarball. The same editor runs on Windows and Mac too.

No account. No subscription.

Download it and use it. There's nothing to sign in to or renew, and your documents stay on your computer.

Text that wraps around pictures.

Square, tight or top-and-bottom wrapping, as in Word. Move the picture and the paragraph follows.

Redactions you can check.

After redacting, Quintess searches the page text, metadata, comments, form data and attachments it can read for any word that should be gone.

One form, every row of a spreadsheet.

Fill a PDF form from a CSV or Excel file and get one filled copy per row, named the way you choose.

Folders that process themselves.

Record a set of steps, then watch a folder: every PDF dropped in gets them. Or script it all from the command line.

The user guide covers each workflow and the differences between platforms.

Questions.

Is Quintess really free?

Yes. It's open source under the MIT or Apache-2.0 license. There's no paid version, no account and no subscription.

Can Quintess replace Acrobat?

For many people, yes: it edits text and pictures, redacts, fills and creates forms, signs, runs OCR and converts documents. It doesn't promise every Acrobat feature or identical results. Try it on copies of your documents and check the results before you switch.

Windows or my Mac warns me about Quintess. Is that normal?

Yes, for now: Quintess isn't code-signed yet. Download it only from the Quintess release page on GitHub, then compare its SHA-256 with the checksum published beside it (in PowerShell: Get-FileHash .\Quintess-*-setup.exe; on a Mac: shasum -a 256 Quintess-*.dmg). A match shows the file is exactly the one released. On Windows, if you decide to go ahead, choose More info, then Run anyway. On a Mac, open Quintess once, then choose Open Anyway in System Settings › Privacy & Security.

Does Quintess work on Mac or Linux?

Yes, both. Version 0.4.4 runs on Macs with Apple silicon or Intel (one app on a disk image) and on Linux, as a .deb for Ubuntu and Debian, an AppImage, a Flatpak or a tarball with an install script. See Installing in the guide.

Does Quintess send my documents anywhere?

No. Your PDF files aren’t uploaded. Editing, OCR and redaction run on your computer. Network access is used for update checks you enable, dictionaries you download, web pages you convert, links you open, and timestamp or certificate-status requests you choose. Optional trusted timestamps send a fingerprint of the signature to a timestamp server. No telemetry.

Run the installer: it sets Quintess up for your user account, with no administrator rights, and adds it to the Start menu and to your PATH. It isn't code-signed yet, so Windows shows a SmartScreen warning. If you trust the download, choose “More info”, then “Run anyway”.

  • On a PC with an ARM processor (Snapdragon and the like), choose the ARM64 installer. The x64 one runs there too, more slowly, and suggests the ARM64 one.
  • Typing quintess in a terminal runs the command-line tool; quintess --help lists its commands.

Disk image

Open the disk image and drag Quintess into Applications. Quintess isn't signed by Apple yet, so macOS won't open it the first time: open System Settings › Privacy & Security, scroll down, and choose Open Anyway beside the message about Quintess. After that it opens normally. Or clear the download mark in Terminal:

xattr -dr com.apple.quarantine /Applications/Quintess.app
  • One app for both Apple silicon and Intel Macs.
  • The command-line tool is inside the app; to type quintess in Terminal, link it once: sudo ln -sf /Applications/Quintess.app/Contents/MacOS/quintess /usr/local/bin/quintess.
  • The Mac version is built and tested automatically on both kinds of Mac, but hasn't been tried by hand yet. Please report problems on GitHub.

On Ubuntu or Debian, download the .deb and install it with apt, which also fetches what it needs:

sudo apt install ./quintess_0.4.4_amd64.deb
.deb package AppImage Flatpak Tarball

Elsewhere: the AppImage runs without installing (make it executable with chmod +x Quintess-*.AppImage, then run it). The Flatpak installs into a sandbox with flatpak install --user Quintess-*.flatpak and needs the Freedesktop runtime from Flathub. The tarball works on any distribution: unpack it and run ./install.sh.

  • Needs glibc 2.35 or later: Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 and newer.
  • Printing uses CUPS, reading aloud speech-dispatcher, and scanning SANE (sane-utils); the .deb suggests them.
  • Inside the Flatpak, scanning and conversion through LibreOffice or a browser aren't available.
