# quintess.cc

The website for Quintess: static pages served by a Cloudflare Worker, which
also keeps a first-party, cookieless visit count in D1.

| Path | What it is |
| --- | --- |
| `public/index.html` | the home page (hand-written) |
| `public/assets/site.css`, `site.js` | the styles, the live demos, the visit count |
| `public/guide/`, `privacy/`, `404.html`, `sitemap.xml` | generated by `tools/build_pages.py`; the guide comes from `docs/USER_GUIDE.md` |
| `public/assets/img/`, `favicon.ico` | generated by `tools/make_images.py` from the program's logo |
| `public/assets/fonts/` | Archivo and JetBrains Mono, self-hosted (SIL Open Font License, licenses beside them) |
| `src/worker.js` | serving, security headers, `www` redirect, `/api/hit`, `/api/release`, `/stats` |
| `schema.sql` | the visit table |

## Working on it

```
npm install
npx wrangler d1 execute quintess-analytics --local --file schema.sql
npx wrangler dev
```

Local secrets go in `.dev.vars` (`STATS_PASSWORD=...`, `VISITOR_SECRET=...`).
After changing `site.css` or `site.js`, run `python tools/build_pages.py`: it
stamps their links with a hash so browsers fetch the new copy.

The homepage preview is an actual capture of Quintess 0.4.4. To refresh it,
build the release app and run `site/tools/capture_preview.ps1` from the
repository root. It creates a sample PDF from `site/tools/preview-notes.md`,
captures the app with its text editor open, and exits. It requires Python
with Pillow; pass `-Python <path>` if Python is not on your PATH. Update the homepage's
caption and alternative text to the version captured. The benchmark section
is labeled separately with the version actually measured; do not relabel
historical results when publishing a new app release.

## Deploying

```
python tools/deploy.py
```

builds the generated pages, deploys, and sends the pages to IndexNow (Bing,
Yandex and others). Google reads `sitemap.xml`, listed in `robots.txt`.

The Worker needs two secrets, set once with `npx wrangler secret put`:
`STATS_PASSWORD` (for `/stats`) and `VISITOR_SECRET` (mixed into the daily
visitor hash). Their values are kept outside the repository.

## Visits

`https://quintess.cc/stats` (any user name, the stats password) shows views,
daily visitors, download clicks, referrers, countries, devices and GitHub's
own installer download counts. What is counted, and what never is, is
explained on `/privacy/`. Rows older than 400 days are deleted daily.
